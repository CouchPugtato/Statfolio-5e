# Spell reference

`spells.json` is the bundled SRD 5.1 spell reference (2014 rules). See [rules attribution](../../RULES-LICENSE.md) and the included MIT notice for source and licensing details.

Regenerate from the pinned source with `node scripts/build-spell-reference.cjs`. To use an already downloaded copy of that source, pass its path as the first argument. The web app reads only the local generated file; it does not contact a spell API.
