# Character sheet template

`character-sheet.pdf` is the original, unmodified [official 2014 fillable character sheet](https://media.dndbeyond.com/compendium-images/marketing/dnd_5e_charactersheet_formfillable.pdf). Its artwork and printed notices remain intact; its own permission notice applies.

`character-sheet-fields.json` maps the spell rows and prepared checkboxes by level. Field names preserve the PDF's original spelling and spaces.

PDF exports fill this template locally in the browser and append continuation pages when the existing boxes are too small.
